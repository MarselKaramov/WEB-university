# Схема архитектуры приложения.

Vue 3 + Vite (localhost:5173) ───────► ASP.NET Core (localhost:5000) ───────►
PostgreSQL (localhost:5432)

# Архитектура web-ИС семестра

1. Vue 3 + Vite

- Рисует три экрана: вход в систему, список заявок, создание заявки.
- Отправляет HTTP-запросы к API.
- Не хранит данные и не знает правил — только отображает то, что вернул сервер.
- В браузере нет доступа к PostgreSQL.

2. ASP.NET Core

- Принимает HTTP-запросы от Vue.
- Проверяет правила: валидация полей, права роли, допустимые переходы статусов.
- Аутентифицирует пользователя и проверяет хеш пароля.
- Генерирует идентификатор заявки и ставит createdAt.
- Обращается к PostgreSQL за данными.
- Возвращает JSON в UTF-8.

3. PostgreSQL

- Хранит все данные: справочники Role, Department, Post, таблицы User,
  Application, StatusHistory, Interview.
- Обеспечивает персистентность: после перезапуска сервера записи на месте.
- Не доступна из браузера напрямую
