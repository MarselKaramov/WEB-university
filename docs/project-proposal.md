## 1. Название и организация

- Название системы: Платформа автоматизации HR-процессов
- Организация / подразделение: Ланит-bpm

## 2. Главная сущность и справочник

- Главный объект (одна запись процесса): Заявка на приём сотрудника
- Справочник (вторая таблица, ссылка числом): Должности
- Поле-ссылка (как назовёте в JSON/БД): post_id

## 3. Роли и права

| Роль                       | Создаёт | Назначает | Меняет статус |
| -------------------------- | ------- | --------- | ------------- |
| Руководитель подразделения | да      | нет       | нет           |
| Руководитель HR-отдела     | нет     | да        | да            |
| HR-специалист              | нет     | да        | да            |
| Технический специалист     | нет     | да        | нет           |

## 4. Сценарий в одно предложение

Руководитель подразделения создает заявку на открытие вакансии → Руководитель
HR-отдела назначает HR-специалиста и меняет статус → HR-специалист назначает
технического специалиста для проведения собеседования и меняет статус →
Технический специалист проводит собеседование и передает решение на платформу →
HR-специалист меняет статус (принят/отказ).

## 6. Что не входит в семестр

1. Мобильное приложение
2. Интеграция с сервисами поиска сотрудников (например, hh.ru)
3. Интеграция с 1С
4. Вычисления KPI сотрудников

## 7. Запас под ВКР

Не меньше **четырёх** пунктов **с разных полок** (данные/процесс · связи с
другими системами · масштаб). В семестре не делают.

1. Сохранение видео-конференций с собеседований;
2. Интеграция с корпоративной почтовой системой;
3. Система оповещений о сроках принятия решений;
4. Автоматическая обратная связь с кандидатом после принятия решения;

## 8. Чем не копия соседа

Другая организация, другая система, другой процесс.
